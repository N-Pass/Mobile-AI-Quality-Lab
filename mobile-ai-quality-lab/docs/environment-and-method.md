## Evaluation method

The case specifications define the inputs and study acceptance criteria. The tester submitted prompts and captured the complete first responses where available. Manual evaluation checks the response against the fictional source and explicit rubric. Equivalent wording is acceptable where the criteria allow it. The same-conversation follow-up is deliberate in MAQL-19.

For mobile flows, observe text preservation, responsiveness and recovery. No instrumented latency, memory, battery or network analysis was performed. Qase duration fields are not app latency measurements. The offline recovery window is a study criterion, not an SLA.

The recorded case results remain authoritative for this report. Do not interpret an unmarked step as a separate case, overwrite historical result data with the repaired repository, or count status-history rows as independent repetitions.
